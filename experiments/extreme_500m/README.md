# 10M to 500M-city grids (Table 4)

Workstation: 32 logical CPUs, 63.7 GB RAM. Engine G3 (≤ 200M) and G4 (300M–500M; flat coordinate index, K set by
available memory). Even-sided unit grids, so the optimal length is exactly N. Each `N*_square/` folder holds
`summary.json`, `runs.csv`, `tours.csv` (validity, recomputed length, SHA-256 per tour), `memory_log.csv` and
`batch_log.txt`. `BIG_EXPERIMENTS_SUMMARY_19Nov.md` is the overview table.
