# `files/` packaging notes

## `lkh_benchmark_kit/`

Fair LKH-3 / NN comparison kit for manuscript **Table 6** (×5 DVD wall-clock budget).

This GitHub tree includes scripts, compact result CSVs (including `results/comparison_master_q1.csv`), `LKH.exe`, and smaller TSP instances. Very large lattices (N=500k/1M) and `lkh_src/` are omitted to keep the repository size practical; regenerate those locally with the kit scripts if needed.
