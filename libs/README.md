# Core Algorithm Library

This folder contains the `TSP_CS.Core.dll` file, which provides the core TSP solving algorithms.

## Important Notes

- **The DLL source code is proprietary and not included in this repository**
- The DLL must be present for the application to build and run
- The DLL is built for .NET 8.0 and Windows platform

## Obtaining the DLL

If the DLL is not present, you can:

1. **Contact the repository maintainer** for a download link
2. **Build from private repository** (if you have access)
3. **Check for updates** - newer versions may be available

## DLL Information

- **Assembly Name:** TSP_CS.Core
- **Namespace:** TSP_CS
- **Target Framework:** .NET 8.0-windows
- **Public Types:**
  - `TspMain` - Main solver engine class
  - `TspDistanceMatrix` - Distance matrix manager

## Version Compatibility

Ensure the DLL version matches the application version. Mismatched versions may cause:
- Missing method errors
- Type mismatch exceptions
- Runtime failures
